# 🛒 Retail Sales Analytics Project

📊 **Data Analysis + SQL + Python + Tableau**

This project presents a complete analysis of retail sales transactions using:
- ✅ SQL (MySQL via DBeaver)
- ✅ Python (Jupyter Notebook)
- ✅ Tableau Public (interactive dashboard)
- ✅ GitHub (portfolio)

---

## 🔍 Project Overview

The dataset includes simulated retail transactions with:
- Transaction date
- Customer demographics (gender, age)
- Product categories
- Quantity and pricing
- Total amount spent

The goal of the project is to identify:
- Which products generate the most revenue?
- What are the monthly sales trends?
- Who spends more – men or women?
- Which age groups contribute the most?
